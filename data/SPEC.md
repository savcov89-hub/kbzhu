# Формат базы продуктов (для сборщиков)

Задача: часть русской базы продуктов и блюд для счётчика калорий (аналог FatSecret для клиентов фитнес-клуба в Новосибирске). Пользователь ищет по-русски, как говорит в жизни: «гречка», «куриная грудка», «борщ», «сырники».

## Файл
JSON-массив объектов, UTF-8, без комментариев. Значения на **100 г съедобной части** (для напитков тоже на 100 г ≈ 100 мл).

```json
{
  "n": "Гречка варёная на воде",
  "g": "Крупы и каши",
  "k": 110,
  "p": 4.2,
  "f": 1.1,
  "c": 21.3,
  "fb": 3.7,
  "a": ["гречневая каша", "греча"],
  "u": [["порция", 200], ["ст. л.", 25]]
}
```

- `n` — название, как ищут люди: главное слово первым («Гречка варёная», «Грудка куриная варёная», «Творог 5%»). Состояние указывать: сырой/варёный/жареный/запечённый, сухая крупа или каша.
- `g` — группа (дана в задании).
- `k` — ккал, целое.
- `p`, `f`, `c` — белки, жиры, **усвояемые** углеводы, г, одна цифра после запятой. Как в российских таблицах (Скурихин, «Химический состав российских пищевых продуктов», МР 2.3.1.0253-21), где углеводы даны без пищевых волокон.
- `fb` — пищевые волокна (клетчатка), г. Для мяса, рыбы, молока, масел — 0. Не пропускать: клетчатку тренер смотрит в отчёте.
- `a` — синонимы и разговорные названия для поиска (0–5 штук), можно пустой массив.
- `u` — типичные порции: `[подпись, граммы]`, 0–4 штуки. Например «шт» (яйцо 55 г съедобной части), «ст. л.», «ч. л.», «стакан», «тарелка» (суп 300 г), «порция», «ломтик», «кусок». Без граммовки «100 г» — она есть всегда.
- `al` — только для алкоголя: граммы этанола на 100 г.

## Правила точности
- Цифры реальные, типичные для российских справочников и упаковок массовых российских продуктов. Не выдумывай экзотику, бери самые частые варианты.
- Проверка энергии: `k ≈ 4·p + 9·f + 4·c + 2·fb (+ 7·al)`, расхождение не больше 10%. Перед сдачей прогони проверку скриптом (python3) по своему файлу и исправь выбросы.
- Готовые блюда — по обычному домашнему или столовскому рецепту (ГОСТ-сборник рецептур, типичная граммовка), с учётом масла при жарке.
- Без дублей внутри файла. Разные жирности и способы приготовления — отдельные записи («Творог 0%», «Творог 5%», «Творог 9%»).
- Не указывай бренды, кроме общепринятых родовых названий («Сырок глазированный», «Чокопай» не надо).

## Сдача
Запиши файл по пути из задания (Write). В ответе — только число записей и список групп, без самих данных.
